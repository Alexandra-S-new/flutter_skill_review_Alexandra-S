Kindertraum

Kindertraum ist eine moderne Flutter-App für einen digitalen Spielzeug-Shop. 
Die Anwendung wurde im Rahmen eines Flutter-Skill-Reviews entwickelt und bildet einen Einkaufsprozess von der Produktsuche bis zum Checkout ab.

Die App konzentriert sich dabei auf eine übersichtliche Benutzeroberfläche, einfache Navigation und eine saubere technische Struktur.
Zu den Funktionen gehören:
 - Startseite mit Übersicht der verfügbaren Spielzeuge
 - Produktsuche nach Titel und Kategorie
 - Produktübersicht mit Bildern, Beschreibung, Preis, Altersempfehlung und weiteren Informationen
 - Warenkorb mit:
    - Hinzufügen und Entfernen von Produkten
    - Erhöhen und Verringern der Anzahl
    - Automatischer Berechnung der Gesamtpreise
    - Leeren des Warenkorbs
 - Checkout-Prozess ohne echte Zahlungsabwicklung -> Dies wurde im Live-Coding im Skill-Review hinzugefügt.
 - Theme-Unterstützung und Gestaltung der Benutzeroberfläche
 - Responsive Darstellung durch Flutter
 - State Management mit Provider

Das Projekt wurde mit folgenden Technologien umgesetzt:
 - Flutter
 - Dart
 - Provider für das State Management
 - Material Design
 - VS Code als Entwicklungsumgebung

Ziel des Projekts war es, die im Rahmen der Flutter-Weiterbildung erlernten Kenntnisse praktisch anzuwenden und eine funktionsfähige mobile Anwendung zu entwickeln.
Das Projekt ist ein funktionaler Prototyp eines Spielzeug-Shops. Der Einkaufsprozess kann vollständig durchgespielt werden, allerdings findet keine echte Bestellung oder Zahlungsabwicklung statt 
und eine Speicherung vom Warenkorb nach dem schließen der App fehlt noch.
